# 🎯 Sayı Tahmini

Java ile geliştirilmiş basit bir sayı tahmin oyunudur.

## 🎮 Özellikler

- Kullanıcıdan isim alma
- 1-10 arasında rastgele sayı oluşturma
- 3 tahmin hakkı
- Tahminin yüksek veya düşük olduğunu belirtme
- Doğru tahminde başarı mesajı
- Yapılan tahminleri listeleme

## 🛠️ Kullanılan Teknolojiler

- Java
- Java Scanner
- Java Math
- Java Arrays

## 🚀 Nasıl Çalıştırılır

Projeyi Java destekleyen bir IDE ile açın ve `Game.java` dosyasını çalıştırın.

## 🧠 Kullanılan Java Konuları

- Metotlar
- Diziler
- `Math.random()`
- Kullanıcıdan veri alma
- Koşul ifadeleri
- String işlemleri
